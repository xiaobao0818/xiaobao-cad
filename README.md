# 🐻 小宝CAD（XiaoBao CAD）

一款完全运行在浏览器中的 **2D/3D CAD 软件**，内置 **AI 大模型助手**：既有专业 2D 制图（图层/标注/命令行/对象捕捉），又有基于 **OpenCASCADE 实体内核**的 **3D 实体建模**（布尔运算/圆角/倒角/STEP），还可以直接用自然语言对话创作，或把图纸文件丢给 AI 做参考来改图、建图、标注。

纯前端实现，**无需构建、无需后端**，打开即用。

> ⚠️ 首次切换到 3D 工作区时需加载 OpenCASCADE 内核（约 63MB WASM，本地加载，仅首次需要几秒）。

## 🚀 快速开始

```bash
# 方式一：用任意静态服务器（推荐）
cd 小宝-cad
npm install          # 安装依赖（three.js + opencascade.js）
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899

# 方式二：直接双击 index.html（部分浏览器会限制 ES 模块，建议用方式一）
```

> Node 仅用于安装依赖与运行自动化测试，软件运行时不需要任何 Node 服务。

## 🤖 配置 AI 助手（AI 原生 CAD 智能体）

> 小宝CAD 的核心目标：**AI 原生 CAD**——用自然语言对话、或给图纸/草图文件作参考，就能完成专业级的制图与建模。AI 助手被设计为一个**专业制图/建模 Agent**：
> - **上下文注入**：每轮请求自动携带「专业 CAD 智能体」角色设定（2D/3D 工程规范、工作流准则）+ 当前图纸/模型的实时状态，模型无需反复查询
> - **专业规范**：中心线、图层惯例、尺寸标注、布局留白、建模顺序、布尔策略等制图规范内置在系统提示中
> - **闭环质量**：创作完成后多模态审阅员按「专业检查清单」看图自检并自动修改，直到满意


1. 点击右侧「🤖 AI 助手」标签 → 右上角 **⚙ 设置**；
2. 项目**统一使用 MiniMax M3**（文本对话、工具调用、多模态看图审阅全部由它完成，只需一个 Key）：
   - **API 地址**：`https://api.minimaxi.com`（默认，自动补全 /v1 路径）
   - **模型**：`MiniMax-M3`（默认）
   - **API Key**：在 [platform.minimaxi.com](https://platform.minimaxi.com) 申请
   - 旧版 DeepSeek 默认配置会自动迁移（视觉 Key 会自动提升为主 Key）
3. Key 仅保存在本浏览器 localStorage，不会上传到任何第三方。
4. 也可在设置里换成任意 OpenAI 兼容接口（地址/模型/Key 均可改），但多模态审阅建议保持 MiniMax。

### 👁 多模态审阅（MiniMax M3 原生多模态）

小宝CAD 引入 [MiniMax M3](https://platform.minimaxi.com/docs/api-reference/text-chat-openai)（1M 上下文、原生多模态、支持函数调用）作为**图纸审阅员**：

- **自动审阅**（默认开启）：每次 AI 创作完成后，自动把当前图纸/模型的**实时渲染截图**发给 MiniMax M3（同一个模型，无需额外配置），让它"看一遍"——发现问题就**直接调用工具修改**，改完再截图再检查，**循环优化直到模型回复「已满意」**
- **手动审阅**：聊天框头部「👁 审阅」按钮随时触发
- **图片参考**：📎 附加 PNG/JPG 草图或参考图，模型直接"看懂"图片照着建模
- **DWG 参考（完整解析）**：📎 附加 DWG 文件时，本软件用内置的 **LibreDWG WASM 解析器**直接加载文件——解析出全部几何实体（线/多段线/圆弧/椭圆/文字/块引用等）与图层，把结果摘要交给模型（模型无需也无法查看原始二进制）；文件菜单「打开」同样支持 DWG，图纸直接加载到画布。标注/样条/填充等复杂对象暂跳过
- 设置里可配置自动审阅开关、审阅轮数上限（0=不限制）、深度思考模式（视觉模型默认与主模型相同，可单独覆盖）
- 安全性：审阅循环无硬性上限，但模型**连续多轮做完全相同修改**时自动停下防死循环；「停止」按钮随时手动打断

### 对话示例

- "帮我画一个 100×60 的矩形，四个角各有一个半径 6 的圆孔"
- "把当前所有圆孔的半径改成 8"
- "给这张图标注总长和总宽"
- "在图中间画一个直径 40 的圆，加中心线，并标直径"
- 📎 上传 `samples/sample_floorplan.dxf` 后问："这个户型有几面墙？把客厅里的柱子删掉，在右上角加一扇半径 900 的门"
- 🧊 3D 模式："创建一个 60×40×30 的长方体，再挖一个直径 20 的通孔" → 创作完成后 MiniMax M3 自动看图审阅并优化

AI 通过**函数调用**直接操作图纸（创建/修改/删除实体、图层、缩放、查询），每批操作可一次撤销；模型不支持函数调用时自动降级为「CAD 命令 JSON」模式。

**工作区感知**：AI 严格跟随当前工作区——在「📐 2D 制图」区只会使用 2D 绘图工具（画线/圆/矩形等），在「🧊 3D 建模」区只会使用三维实体工具（建体/布尔/变换），工具集随工作区切换动态过滤，互不串扰。

## ✨ 功能清单

### 🧊 3D 实体建模（顶栏「3D 建模」工作区，OpenCASCADE 内核）
- **基本体**：长方体 / 圆柱 / 球 / 圆锥 / 圆环（对话框参数化创建）
- **布尔运算**：并集 ∪ / 差集 − / 交集 ∩（点击选择两个实体即运算，真实 B-rep 实体布尔）
- **圆角/倒角**：选中实体一键对全部棱边圆角（⧉）或倒角（⌐）；AI 也可用 `fillet_3d` / `chamfer_3d` 工具
- **编辑**：移动 / 三轴旋转 / 缩放 / 改色 / 删除，撤销重做（Ctrl+Z / Ctrl+Y）
- **视图**：鼠标左键旋转 · 滚轮缩放 · 右键平移 · 点击实体选择高亮 · 适应视图
- **文件**：导入 STEP（.step/.stp，SolidWorks/CATIA/Creo 通用格式）、导出 STEP、导出 STL（3D 打印）
- 三维模型随图纸一起保存进 .xbcad.json 原生格式
- **AI 三维对话**："创建一个 60×40×30 的长方体，再挖一个直径 20 的通孔"→ AI 自动建体、布尔、变换

### 📐 2D 制图（原工作区）
### 绘图
直线 `L` · 多段线 `PL`（支持 C 闭合、凸度弧段）· 矩形 `REC` · 多边形 `POL` · 圆 `C`（圆心/2P/3P）· 圆弧 `A`（三点/SCE/SCA）· 椭圆 `EL` · 点 `PO` · 单行文字 `TEXT` · 图案填充 `H`（实心/斜线）

### 修改
移动 `M` · 复制 `CO` · 旋转 `RO` · 缩放 `SC`（含参照 R）· 镜像 `MI` · 偏移 `O` · 修剪 `TR` · 延伸 `EX` · 圆角 `F` · 倒角 `CHA` · 矩形阵列 `AR` · 环形阵列 `ARP` · 拉伸 `S`（交叉窗口）· 删除 `E` · 分解 `X` · 编辑文字 `ED`

### 标注与块
线性 `DLI` · 对齐 `DAL` · 半径 `DRA` · 直径 `DDI` · 角度 `DAN` · 标注样式 `DDIM` · 定义块 `B` · 插入块 `I`

### 专业特性
- **图层**：新建/删除/重命名/开关/锁定/颜色/当前层，实体可随层或独立设置颜色、线型（实线/虚线/中心线/点划线…）、线宽
- **对象捕捉**：端点/中点/圆心/象限点/交点/最近点/节点，带彩色捕捉标记
- **正交模式 F8**、**栅格 F7**、**栅格捕捉 F9**、自适应 1-2-5 栅格
- **命令行**：支持绝对坐标 `100,50`、相对坐标 `@20,10`、极坐标 `@50<45`，回车重复命令，↑/↓ 历史
- **选择**：点选、Shift 加减选、窗选（左→右）/交叉窗选（右→左）、全选、属性面板批量改图层/颜色/线型/线宽与几何参数（半径、字高、文字内容等）
- **撤销/重做**（200 步）、自动保存（25 秒，刷新自动恢复）
- 视图：滚轮缩放（以光标为中心）、中键/右键拖动平移、缩放窗口/范围/全部

### 文件读写
| 格式 | 读取 | 写出 | 说明 |
|---|---|---|---|
| **DXF** (R12/R2000) | ✅ | ✅ | LINE / LWPOLYLINE / POLYLINE / CIRCLE / ARC / ELLIPSE / TEXT / MTEXT / POINT / INSERT(块递归) / DIMENSION / HATCH(边界) / SOLID |
| **STEP** (.step/.stp) | ✅ | ✅ | 三维实体模型（OpenCASCADE 内核，与 SolidWorks/CATIA/Creo 互通） |
| **STL** | — | ✅ | 3D 打印网格导出 |
| **小宝CAD JSON**（.xbcad.json） | ✅ | ✅ | 原生格式，完整保留 2D+3D 全部特性 |
| **SVG** | ✅（完整 path 命令） | ✅ | 线/折线/矩形/圆/椭圆/路径(M/L/H/V/C/S/Q/T/A/Z + 相对命令)/文字 + transform(matrix/translate/scale/rotate/skew) + 颜色/线宽 |
| **PNG** | — | ✅ | 白底截图导出 |
| **DWG** | ✅（LibreDWG WASM） | — | 浏览器内直接解析（线/LWPOLYLINE/传统 POLYLINE2D/3D/圆弧/椭圆/文字/块引用/图层）；标注/样条/填充等复杂对象暂跳过 |

## 🗺️ 技术路线与已知限制

- 渲染基于 Canvas 2D，世界坐标系 Y 轴向上，单位为 mm（DXF 单位随文件）。
- 修剪/延伸/圆角/倒角支持线、圆、弧、多段线（含凸度）；椭圆参与修剪时按采样折线近似。
- 多段线偏移采用采样折线 + 斜接顶点近似；非等比缩放下的弧段自动扁平化。
- DWG 为专有格式，需第三方工具转 DXF（见上表）。
- 复杂 DXF 对象（SPLINE 样条、MLINE 多线、LEADER 引线、3DFACE、非折线边界的复杂填充）读取时跳过，写出时降级。

## 🎓 画图训练循环（AI 训练 + MiniMax 多模态验收）

`tests/train-loop.html` 提供可持续运行的「画图训练 → 多模态验收 → 质量打分」闭环：

- **任务库**（`training/tasks.mjs`）：基础任务（2D 法兰盘/支架轮廓、3D 四孔板/轴套）+ **工业级水泵组件任务**（3D 叶轮/泵壳/台阶轴、2D 水泵剖视图），每个任务带确定性验收标准（实体类型/数量/几何尺寸/布尔结构/同轴度/台阶数/叶片环形均布/轴段总长）
- **验收器**（`training/acceptance.mjs`）：对 AI 画出的图纸/模型打 0-100 分（纯函数，node 可测，`node tests/training-acceptance.test.mjs`）
- **训练循环页**：逐任务多轮循环——AI 画图 → 验收打分 → MiniMax M3 截图审阅 → 修复 → 再打分，记录每轮 Δ 分并支持导出训练日志 JSON
- **两种模式**：
  - `?mock=1`：本地 mock 服务器（先 `python3 tests/mock-ai-server.py`），剧本故意留缺陷（漏孔/漏布尔）由审阅补上，验证闭环
  - 默认：使用你在「AI 设置」里配置的真实 MiniMax M3 Key，进行真实多模态验收
- 质量提升可量化：验收分数曲线、审阅前后 Δ 分、审阅轮数全部落盘（`localStorage: xbcad:training-log`）
- **训练日志分析页**（`tests/train-stats.html`）：按任务聚合的验收前后均分/平均提升/审阅有效率/满意度 + 质量柱状曲线 + 近期达成度（≥90 分判"已学会该任务"），支持导入训练日志 JSON
- **装配配合验收**：`fitClearance` 检查轴孔间隙配合（缺件/干涉/间隙超差），已用于微型泵整机装配任务（轴 Φ60 / 叶轮孔 Φ61）；`fitChain` 多级配合链（轴→叶轮孔→轴承孔逐级同轴、间隙为正），已用于两级离心泵任务
- **浏览器端到端验证**（`npm run test:e2e`，puppeteer-core 驱动本机 Chrome）：真实浏览器中跑训练闭环并断言「缺陷画图低分 → 多模态审阅修复 → 复审高分 → 日志落盘 → 统计页渲染」；`TASK=minipump3d` 切换单任务，`ALL=1` 全任务回归（11/11 任务审阅修复后均 100 分）
- **蜗壳型线验收**：`spiralGrowth`（切圆圆心沿螺旋线渐进放大）+ `angularEven`（叶片角度均布，叶轮叶片均分验收）
- **验收反馈闭环**：验收 <100 分时自动把失败检查明细作为修复指令发给模型，最多 3 轮反馈直至满分（不依赖多模态也可自我修复；`?noreview=1` 可单独验证该闭环）
- **持续训练模式**：`?continuous=1` 无限循环、**最少训练次数优先 + 同层级弱项加权随机**选择任务（保证每个任务先练一遍），日志持续累积，适合挂机训练
- **工业设计规范注入**（`training/specs.mjs`）：6 类水泵设计规范（叶片数/后弯角、蜗壳隔舌间隙、轴肩圆角/公差、H7/f7 配合、法兰跨中布置等）按任务自动附加到训练提示，真实模型训练时受益
- **真实 MiniMax M3 验收已跑通**（`REAL=1 MINIMAX_KEY=... npm run test:e2e`）：微型泵整机任务真实模型绘制 74 分 → 多模态审阅 2 轮 → 87 分（Δ+13）；AI 助手新增「模型不调用工具时解析其 CAD JSON 代码块 + 二次提示调用工具」兜底（针对 M3 偶发只输出文字计划）
- **真实模型验收明细**：验收器输出逐项 ✓/✗ 且**带实测数值**（圆心距/角度/偏心量列表，如"box 圆心距 [35.1, 28.3, 35.0]，命中 5/6"），可直接定位并修正模型薄弱点
- **跨轮薄弱点记忆**（`training/memory.mjs`）：每轮失败明细落盘（日志 `fails` 字段），历史扣分按类别聚合后自动注入下一轮训练提示——真实模型"记住"错误、越练越好；实测 85 分画图经验收反馈 2 轮修到 100 分（Δ+15）
- **真实模型实测记录**：法兰盘 85→100（反馈修复）；微型泵 74→87→**100 分全项通过**（多模态审阅 + 数值反馈修好叶片均布）；规范注入后首轮即 100；薄弱点记忆注入第 2 轮提示 ✓
- **训练报告导出**：统计页「导出 Markdown 训练报告」（`training/report.mjs`）——整体趋势/按任务/最近明细/薄弱点一章式报告
