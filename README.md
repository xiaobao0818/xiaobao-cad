# 🐻 小宝CAD（XiaoBao CAD）

一款完全运行在浏览器中的 **2D/3D CAD 软件**，内置 **AI 大模型助手**：既有专业 2D 制图（图层/标注/命令行/对象捕捉），又有基于 **OpenCASCADE 实体内核**的 **3D 实体建模**（布尔运算/圆角/倒角/STEP），还可以直接用自然语言对话创作，或把图纸文件丢给 AI 做参考来改图、建图、标注。

纯前端实现，**无需构建、无需后端**，打开即用。

> ⚠️ 首次切换到 3D 工作区时需加载 OpenCASCADE 内核（约 63MB WASM，本地加载，仅首次需要几秒）。

---

## 🚀 快速开始

```bash
# 方式一：用任意静态服务器（推荐）
cd 小宝-cad
npm install          # 安装依赖（three.js + opencascade.js）
python3 -m http.server 8899
# 浏览器打开 http://localhost:8899

# 方式二：直接双击 index.html（部分浏览器会限制 ES 模块，建议用方式一）
```

> Node 仅用于安装依赖与运行自动化测试，软件运行时不需要任何 Node 服务。

## 🤖 配置 AI 助手

1. 点击右侧「🤖 AI 助手」标签 → 右上角 **⚙ 设置**；
2. 填入大模型接口（默认 **DeepSeek**，兼容所有 OpenAI 风格接口，如 Qwen、GLM、Kimi、OpenAI 等）：
   - **API 地址**：`https://api.deepseek.com`（默认）
   - **模型**：`deepseek-chat`（默认）
   - **API Key**：在 [platform.deepseek.com](https://platform.deepseek.com) 申请
3. Key 仅保存在本浏览器 localStorage，不会上传到任何第三方。

### 👁 多模态审阅（MiniMax M3 原生多模态）

小宝CAD 引入 [MiniMax M3](https://platform.minimaxi.com/docs/api-reference/text-chat-openai)（1M 上下文、原生多模态、支持函数调用）作为**图纸审阅员**：

- **自动审阅**（默认开启）：每次 AI 创作完成后，自动把当前图纸/模型的**实时渲染截图**发给 MiniMax M3，让它"看一遍"——发现问题就**直接调用工具修改**，改完再截图再检查，**循环优化直到模型回复「已满意」**
- **手动审阅**：聊天框头部「👁 审阅」按钮随时触发
- **图片参考**：📎 附加 PNG/JPG 草图或参考图，模型直接"看懂"图片照着建模
- **DWG 参考**：📎 支持附加 DWG 文件——自动识别版本并提取其中的文字/图层/块名等文本信息供 AI 参考；完整几何需转 DXF 后附加（浏览器无法解析专有二进制）
- 设置里可配置视觉模型（默认 `MiniMax-M3` @ `https://api.minimaxi.com`，视觉 Key 默认沿用主 Key）、自动审阅开关、审阅轮数上限（0=不限制）、深度思考模式
- 安全性：审阅循环无硬性上限，但模型**连续多轮做完全相同修改**时自动停下防死循环；「停止」按钮随时手动打断

### 对话示例

- "帮我画一个 100×60 的矩形，四个角各有一个半径 6 的圆孔"
- "把当前所有圆孔的半径改成 8"
- "给这张图标注总长和总宽"
- "在图中间画一个直径 40 的圆，加中心线，并标直径"
- 📎 上传 `samples/sample_floorplan.dxf` 后问："这个户型有几面墙？把客厅里的柱子删掉，在右上角加一扇半径 900 的门"
- 🧊 3D 模式："创建一个 60×40×30 的长方体，再挖一个直径 20 的通孔" → 创作完成后 MiniMax M3 自动看图审阅并优化

AI 通过**函数调用**直接操作图纸（创建/修改/删除实体、图层、缩放、查询），每批操作可一次撤销；模型不支持函数调用时自动降级为「CAD 命令 JSON」模式。

## ✨ 功能清单

### 🧊 3D 实体建模（顶栏「3D 建模」工作区，OpenCASCADE 内核）
- **基本体**：长方体 / 圆柱 / 球 / 圆锥 / 圆环（对话框参数化创建）
- **布尔运算**：并集 ∪ / 差集 − / 交集 ∩（点击选择两个实体即运算，真实 B-rep 实体布尔）
- **编辑**：移动 / 三轴旋转 / 缩放 / 改色 / 删除，撤销重做（Ctrl+Z / Ctrl+Y）
- **视图**：鼠标左键旋转 · 滚轮缩放 · 右键平移 · 点击实体选择高亮 · 适应视图
- **文件**：导入 STEP（.step/.stp，SolidWorks/CATIA/Creo 通用格式）、导出 STEP、导出 STL（3D 打印）
- 三维模型随图纸一起保存进 .xbcad.json 原生格式
- **AI 三维对话**："创建一个 60×40×30 的长方体，再挖一个直径 20 的通孔"→ AI 自动建体、布尔、变换

### 📐 2D 制图（原工作区）
### 绘图
直线 `L` · 多段线 `PL`（支持 C 闭合、凸度弧段）· 矩形 `REC` · 多边形 `POL` · 圆 `C`（圆心/2P/3P）· 圆弧 `A`（三点/SCE/SCA）· 椭圆 `EL` · 点 `PO` · 单行文字 `TEXT` · 图案填充 `H`（实心/斜线）

### 修改
移动 `M` · 复制 `CO` · 旋转 `RO` · 缩放 `SC`（含参照 R）· 镜像 `MI` · 偏移 `O` · 修剪 `TR` · 延伸 `EX` · 圆角 `F` · 倒角 `CHA` · 矩形阵列 `AR` · 环形阵列 `ARP` · 拉伸 `S`（交叉窗口）· 删除 `E` · 分解 `X` · 编辑文字 `ED`

### 标注与块
线性 `DLI` · 对齐 `DAL` · 半径 `DRA` · 直径 `DDI` · 角度 `DAN` · 标注样式 `DDIM` · 定义块 `B` · 插入块 `I`

### 专业特性
- **图层**：新建/删除/重命名/开关/锁定/颜色/当前层，实体可随层或独立设置颜色、线型（实线/虚线/中心线/点划线…）、线宽
- **对象捕捉**：端点/中点/圆心/象限点/交点/最近点/节点，带彩色捕捉标记
- **正交模式 F8**、**栅格 F7**、**栅格捕捉 F9**、自适应 1-2-5 栅格
- **命令行**：支持绝对坐标 `100,50`、相对坐标 `@20,10`、极坐标 `@50<45`，回车重复命令，↑/↓ 历史
- **选择**：点选、Shift 加减选、窗选（左→右）/交叉窗选（右→左）、全选、属性面板批量改图层/颜色/线型/线宽与几何参数（半径、字高、文字内容等）
- **撤销/重做**（200 步）、自动保存（25 秒，刷新自动恢复）
- 视图：滚轮缩放（以光标为中心）、中键/右键拖动平移、缩放窗口/范围/全部

### 文件读写
| 格式 | 读取 | 写出 | 说明 |
|---|---|---|---|
| **DXF** (R12/R2000) | ✅ | ✅ | LINE / LWPOLYLINE / POLYLINE / CIRCLE / ARC / ELLIPSE / TEXT / MTEXT / POINT / INSERT(块递归) / DIMENSION / HATCH(边界) / SOLID |
| **STEP** (.step/.stp) | ✅ | ✅ | 三维实体模型（OpenCASCADE 内核，与 SolidWorks/CATIA/Creo 互通） |
| **STL** | — | ✅ | 3D 打印网格导出 |
| **小宝CAD JSON**（.xbcad.json） | ✅ | ✅ | 原生格式，完整保留 2D+3D 全部特性 |
| **SVG** | ✅（基础图元） | ✅ | 线/折线/矩形/圆/椭圆/路径/文字 |
| **PNG** | — | ✅ | 白底截图导出 |
| **DWG** | ⚠️ | — | Autodesk 专有格式，浏览器无法直接解析；请先用 [ODA File Converter](https://www.opendesign.com/guestfiles/oda_file_converter) 或 LibreDWG（`dwg2dxf`）转换为 DXF 后打开 |

## 🗺️ 技术路线与已知限制

- 渲染基于 Canvas 2D，世界坐标系 Y 轴向上，单位为 mm（DXF 单位随文件）。
- 修剪/延伸/圆角/倒角支持线、圆、弧、多段线（含凸度）；椭圆参与修剪时按采样折线近似。
- 多段线偏移采用采样折线 + 斜接顶点近似；非等比缩放下的弧段自动扁平化。
- DWG 为专有格式，需第三方工具转 DXF（见上表）。
- 复杂 DXF 对象（SPLINE 样条、MLINE 多线、LEADER 引线、3DFACE、非折线边界的复杂填充）读取时跳过，写出时降级。
